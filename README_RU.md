# Чистые UV-шаблоны ракеток

Два независимых атласа 2048×2048, без artwork и **без надписей внутри файлов**:

- `rubber_atlas_template.png` — накладки;
- `handle_atlas_template.png` — рукоятки.

Сковорода сюда не входит: она использует собственную заливку текстурой и не требует этого атласа.

## Накладки

В каждой из 15 ячеек находятся:

- внешний цветной пунктирный круг — контроль краёв головы;
- внутренний светлый пунктирный круг — безопасная область главного рисунка;
- перекрестие и центральные направляющие — центровка artwork;
- отдельная прямоугольная область внизу — кромка резины.

Круги центрированы по координатам исходной UV-области головы `(400, 400)` в master-разметке 1024×1024, а не по пустому пространству всей ячейки. Поэтому на готовой ракетке перекрестие попадает в центр головы. Наружный радиус — 370 master px, внутренний — 270 master px.

## Рукоятки

Только цветные прямоугольники, без букв и текста:

- синий — передняя половинка A вместе с правой боковой гранью R;
- зелёный — задняя половинка B вместе с левой боковой гранью L;
- жёлтый квадрат — торец.

Таким образом используются только две цельные цветовые стороны, без четырёхцветных полос на изгибе. Каждый боковой прямоугольник R/L — непрерывная полоса: передняя и задняя половинки встречаются в центре без пустого разрыва.

Боковая развёртка больше не выбирает область по наклону нормали. Два фиксированных сегмента каждой кромки — вертикальная грань и прилегающая фаска — всегда попадают в соответствующий R/L-прямоугольник. Координата U строится по реальной длине контура, поэтому текстура не сжимается на скруглениях и не растягивается на верхнем плечике.

Внутренние белые обводки цветных UV-областей удалены: они выглядели на модели светлыми треугольниками из-за mip-фильтрации. У цветных областей добавлен bleed 4 master px, поэтому mipmaps остаются внутри нужного цвета.

Геометрия, посадка и общая раскладка ячеек не изменены. Изменена только UV-развёртка боковых граней внутри прежних R/L-зон.

Одна ячейка работает для Flared, Straight и Anatomic. Деревянная центральная пластина в атлас не входит.

## Коллекции и расцветки

Названия коллекций и расцветок вынесены из изображения в отдельные файлы:

- `mapping/atlas_mapping.csv` — все 45 сочетаний;
- `mapping/atlas_mapping.json` — номера ячеек, цветовые страницы и точные UV-координаты.

Положение ячейки не меняется между `v01`, `v02` и `v03`.

## Координаты

- страница: 2048×2048 px;
- сетка: 5×3;
- ячейка: 384×384 px;
- сэмплируемая область: 360×360 px;
- bleed: 12 px;
- промежуток: 16 px;
- начало сетки: `[32, 432]`;
- шаг: 400 px.

Формула остаётся прежней:

```text
atlasUV = cellInnerOffset + originalUV * cellInnerScale
```

## Проверка

`template_viewer.html` показывает эти чистые шаблоны на неизменённых моделях. Проверены 15 коллекций, 225 независимых сочетаний накладок и рукояток, все четыре формы головы и три формы рукоятки. Ошибок WebGL нет.

Пересборка:

```bash
python3 source/build_template.py
python3 source/validate_template.py
```
